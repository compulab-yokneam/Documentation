# SIM7672 H2

1) Place the SIM7672G into ECM mode (instead of RNDIS) with commands:
    ```
    AT+DIALMODE=0
    AT$MYCONFIG="usbnetmode",1
    ```
2) Set and save the APN via the following:
    ```
    AT+CGDCONT=1,"IP","iot.tmowholesale"
    AT&W
    ```
3) Restart the modem:
    ```
    AT+CFUN=0
    AT+CFUN=1
    ```
4) Confirm APN remained set and didn't revert to default:
    ```
    AT+CGDCONT? 
    ```
    * If still reverting to default, issue command:
        ```
        AT$QCNVMAPNE=1,1,,"IP","iot.tmowholesale","LTE"
        ```
5) Confirm signal strength and registration:
    ```
    AT+CSQ and AT+COPS?
    AT+CEREG?
    ```
6) Run dhclient on the host to obtain an IP address. The interface should appear as 'eth1' or similar, and routing etc will be set up by dhclient.
    ```
    dhclient eth1
    ```
7) Test with ``ping -I eth1 8.8.8.8`` to confirm internet connectivity:
    ```
    ping -I eth1 8.8.8.8
    ```
